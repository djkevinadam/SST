  Status     : Independent / Open Source


  [ ABOUT ]

  SST (Serato Stem Tool) is an independent utility
  designed to work with Serato Stem Containers.

  Extract, convert, and rebuild stem audio without
  relying on Serato DJ's built-in stem processing.

  No subscriptions.
  No accounts.
  No unnecessary restrictions.


  [ FEATURES ]

  - Extract audio stems from .serato-stems containers
  - Rebuild Serato Stem Containers
  - Individual stem handling:
      * Vocals
      * Bass
      * Drums
      * Melody
  - WAV, FLAC and MP3 audio support
  - MP3 conversion through FFmpeg / LAME
  - Waveform display and seeking
  - Audio output-device settings
  - Drag-and-drop interface
  - Desktop GUI powered by PySide6


  [ INSTALLATION ]

  macOS — APPLE SILICON

  1. Download the SST release package.
  2. Extract the downloaded archive.
  3. Move SST.app into Applications.
  4. Control-click SST.app and select Open.
  5. Confirm the macOS security prompt if presented.

  NOTE:
  This independent build may not be signed with an
  Apple Developer ID or notarized by Apple.

  Do not disable Gatekeeper globally just to run SST.


  [ HOW TO USE ]

  1. Launch SST.
  2. Load or drag a supported .serato-stems file.
  3. Select the stem you want to work with.
  4. Extract or convert the audio.
  5. Save the resulting audio.
  6. Rebuild the container when required.
  7. Load the resulting container in Serato DJ.

  Always retain an untouched backup of your originals.
